# Forbidden 🛡️

코인 관련 사이트와 앱에서 잠시 거리를 두기 위한 Android 자기통제 앱입니다.
사용자가 등록한 사이트·앱·검색어를 감지하고, 경고 문구와 나의 다짐을 보여줍니다.

> **또 만회하러 왔습니까?**
> 지난번에도 ‘이번 한 번만’이었습니다.

## 주요 기능

### 사이트 감지
- 국내외 거래소·커뮤니티·시세 사이트를 선택해 추가
- 업비트, 빗썸, 바이낸스, 코인판 등 지원
- 도메인 직접 입력 및 하위 도메인 감지
- Chrome에서 대상 사이트 접근 시 경고 표시

### 앱 실행 감지
- 바이낸스, 업비트, 코인니스 등 앱을 선택해 추가
- 패키지명 직접 입력 지원
- 대상 앱 실행을 감지하면 홈으로 이동

### Chrome 검색어 감지
- 검색어 감지 켜기·끄기
- 감지 키워드 직접 설정
- 검색 후 주소창에 표시되는 검색어나 검색 결과 URL을 확인
- 페이지 본문은 검사하지 않음

### 나만의 경고 화면
- 경고 제목·보조 문구·나의 다짐 설정
- 저장 전 미리보기
- ‘지금 멈추고 홈으로’ 버튼
- 메인 화면 다크 모드 지원

## 사용 방법

1. 감지할 사이트와 앱을 선택하거나 직접 입력합니다.
2. 필요하면 검색어 감지를 켜고 키워드를 설정합니다.
3. 경고 문구와 나의 다짐을 작성합니다.
4. **규칙 저장**을 누릅니다.
5. 다음 경로에서 접근성 서비스를 활성화합니다.

   **설정 → 접근성 → 설치된 앱 → Forbidden 감시 서비스 → 사용하기**

검색어 감지 스위치는 즉시 적용됩니다.
키워드와 다른 설정을 수정한 뒤에는 규칙을 저장해주세요.

## 동작 방식과 제한

- Android 접근성 서비스를 사용합니다.
- 사이트·검색어 감지는 Chrome에서만 동작합니다.
- 검색 URL 분석은 Google(.com·.co.kr), 네이버, 다음, Bing을 지원합니다.
- Chrome이 주소창 정보를 제공하지 않으면 감지하지 못할 수 있습니다.
- 네트워크 요청이나 앱 설치 자체를 차단하는 방식은 아닙니다.
- 접근성 서비스가 꺼져 있으면 감지가 동작하지 않습니다.
- Android·Chrome 버전과 기기 환경에 따라 동작 차이가 있을 수 있습니다.

## 데이터 처리

- 차단 목록과 경고 문구는 앱의 로컬 설정에 저장합니다.
- 접근성으로 읽은 정보를 개발자 서버로 전송하는 기능은 없습니다.
- Android 시스템 백업 설정에 따라 저장된 설정이 백업될 수 있습니다.

## 개발 환경

- Java 11
- Android SDK: compileSdk 35 / targetSdk 35
- 최소 지원: Android 7.0 · API 24
- AndroidX · Material Components

## 빌드

    ./gradlew :app:assembleDebug

생성 파일: `app/build/outputs/apk/debug/app-debug.apk`

## 검증

    ./gradlew :app:testDebugUnitTest :app:lintDebug

현재 개발 중인 프로젝트이며, 모든 기기에서의 차단 동작을 보장하지 않습니다.
